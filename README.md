# HousePriceAnalyzer

HousePriceAnalyzer
A machine learning application developed in C# using ML.NET for real estate price prediction. The project implements a complete data pipeline, including data preprocessing, feature handling, model training, and evaluation using regression algorithms to estimate property prices. It demonstrates the integration of machine learning capabilities into a .NET application.

C# & ML.NET application for real estate price prediction using machine learning regression models and data pipelines.
